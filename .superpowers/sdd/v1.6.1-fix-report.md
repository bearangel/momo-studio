# v1.6.1 补丁修复报告

Final whole-branch review 发现的 2 个 Important + 1 个 Minor 问题，全部修复。

## 修改清单

### Fix #1（Important）：AddToWorkspaceDialog Layer 3 deltas 首次 spawn 不生效

**根因**：`addAgent` 内部同步 spawn agent（此时 instanceId 还没 deltas），随后才 `setAssignmentDeltas(instanceId, deltas)`，导致用户折叠区内设置的能力 add/remove 在首次 spawn 时完全不影响 agent。

**修复**：setAssignmentDeltas 成功后调 `stopAgent(instanceId)` + `startAgent(newAssignment, ws.id, ws.teamRoomId)`；workspace 已删除则只 stop 不 start。

**修改文件**：
- `renderer/src/components/agent/AddToWorkspaceDialog.tsx`
  - `useAgentStore()` 解构追加 `stopAgent, startAgent`
  - `handleSubmit`：`if (!isEmptyDeltas(deltas))` 块内 setAssignmentDeltas 之后追加 `ipc.workspace.get → stopAgent → if(ws) startAgent` 重启序列
- `renderer/src/components/agent/AddToWorkspaceDialog.test.tsx`
  - 抽出 `stopAgentMock` / `startAgentMock` / `workspaceGet` mock，`beforeEach` 加 mockReset
  - 新增 2 个测试：
    - 「填了 deltas 后提交 → setAssignmentDeltas 后自动 stop+start 重启（顺序正确）」——断言四个 mock 按序调用 + startAgent 参数正确
    - 「填了 deltas 且 workspace 已删除 → 只 stop 不 start」——ws=null 守卫

### Fix #2（Important）：builtin catalog item 在 marketplace install 时显式赋 24 工具

**根因**：`installer.createInlinePackage` 对 agent 类型写 `defaultTools: []`（空数组），导致 marketplace 安装的 builtin agent 在 `registerInstalledPackage` 落库后 `def.defaultTools` 为空。Layer 3 弹窗（AssignmentCapabilitiesDialog）会显示「默认 0 工具」，用户 remove bash 等操作语义错误。

**修复**：从 `electron/src/main/agent/tools/catalog.ts` import `ALL_BUILTIN_TOOLS`，inline agent 包的 `defaultTools` 改为 `ALL_BUILTIN_TOOLS.map((ref) => ({ kind: 'builtin', ref }))`，与 Migration v16 builtin YAML 同步策略一致。

**修改文件**：
- `electron/src/main/marketplace/installer.ts`
  - 新增 import `ALL_BUILTIN_TOOLS`
  - `createInlinePackage` 中 agent 分支的 `defaultTools` 从 `[]` 改为 24 工具数组
- `electron/tests/marketplace/installer.test.ts`
  - 新增测试：「agent 类型 manifest.yaml 含全部 24 个 builtin defaultTools」——解析 YAML 断言长度 24、kind 全为 builtin、包含代表性工具名

### Fix #3（Minor）：DefinitionEditor defToCapabilities 与 capability-helpers 重复

**根因**：`DefinitionEditor.tsx:26-32` 本地副本与 `capability-helpers.ts:39-45` 完全重复。

**修复**：删除本地实现，改 `import { defToCapabilities } from '../../lib/capability-helpers'`。

**修改文件**：
- `renderer/src/components/agent/DefinitionEditor.tsx`
  - 删除本地 `defToCapabilities` 函数（7 行）
  - 新增 import
