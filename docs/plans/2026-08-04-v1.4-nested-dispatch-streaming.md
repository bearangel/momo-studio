# v1.4 委派嵌套流式展示 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** dispatch/task_reply 从独立顶层消息降级为 PM 流式气泡内的嵌套展示，解决多 agent 场景下的内容重复/对话打断/回复脱节问题。

**Architecture:** 子 agent 的 stream chunks 通过 `parentStreamSessionId` 关联到 PM 的 stream session，renderer 嵌套渲染到 PM 气泡内对应的 dispatch tool chip 下方。dispatch/task_reply Matrix 事件不再独立渲染。

**Tech Stack:** Electron (CommonJS) + React (ESM) + Zustand

- [ ] **Step 2: chunk 处理增强**

```tsx
function DispatchProgress({ children }: { children: DispatchChild[] }) {
  const completed = children.filter(c => c.status === 'completed' || c.status === 'failed').length;
  const total = children.length;
  if (completed === total) return null;  // 全部完成，不显示

      ⏳ 等待 {completed}/{total} 子任务完成
```

- [ ] **Step 1: 主进程维护 parent→children 映射**

```typescript
/** streamSessionId → 子 streamSessionId 列表（dispatch 嵌套关系） */
const streamChildren = new Map<string, Set<string>>();

// relayStreamChunk 中，start chunk 含 parentStreamSessionId 时：
if (chunk.type === 'start' && chunk.parentStreamSessionId) {
  const children = streamChildren.get(chunk.parentStreamSessionId) ?? new Set();
  children.add(chunk.streamSessionId);
  streamChildren.set(chunk.parentStreamSessionId, children);
}
```

- [ ] **Step 2: abortStream 传播到子 agent**

```typescript
export function abortStream(roomId: string): void {
  const entry = activeStreams.get(roomId);
  if (entry) {
    safeChildSend(entry.child, { type: 'abort', streamSessionId: entry.streamSessionId });
    // 传播到子 agent streams
    const children = streamChildren.get(entry.streamSessionId);
    if (children) {
      for (const childSessionId of children) {
        // 查找子 session 对应的 child process
        for (const [, activeEntry] of activeStreams) {
          if (activeEntry.streamSessionId === childSessionId) {
            safeChildSend(activeEntry.child, { type: 'abort', streamSessionId: childSessionId });
          }
        }
      }
    }
  }
}
```

- [ ] **Step 3: end chunk 时清理映射**

在 relayStreamChunk 中，`end` chunk 清理 streamChildren：

```typescript
if (chunk.type === 'end') {
  // 清理子映射
  streamChildren.delete(chunk.streamSessionId);
  // 从父的子集合中移除
  for (const [, children] of streamChildren) {
    children.delete(chunk.streamSessionId);
  }
}
```
