# 2.0.0 P3「半成品处置 + IPC 收敛」实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 兑现 spec §9 半成品处置清单（挂载 #T-xxx 双语法输入框、补看板 assignee 筛选与「进入执行会话」、挂载 L2 能力编辑、能力配置归一、资源库 IPC 收敛）+ P1/P2 终审移交项（platform 运行时接线、会话模型 fallback 消费、testConnection 兜底统一、audit 分支 try/catch 等收尾）。

**Architecture:** 两个簇并行推进——功能处置簇（T2-T5：UI 挂载/补完，均为 renderer 侧小改 + 既有后端接线）与运行时收尾簇（T6-T7：platform 显式透传替换 baseUrl 启发式、defaultChatModel 作为 agent 未配置时的 fallback）。IPC 收敛簇（T8：mcp/skill 注册面并入 resource:* + 废弃通道删除）收尾，T9 验收。所有后端管道 P1/P2 已就绪，本计划以「接线 + 挂载 + 删除」为主，零新架构。

**Tech Stack:** Electron 主进程（CommonJS）+ React/Zustand（ESM）。零新增依赖。

**上游 spec:** `docs/specs/2026-08-23-v2.0.0-platform-refactor-design.md` §9（半成品处置）。
**上游裁决:** P1 终审 P2 清单残留 + P2 终审 P3 记账（README 技术债表 + progress.md ledger）。
