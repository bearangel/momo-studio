# v2.2 Agent 记忆系统 P2（Agent 工具 + 自动提取 + 会话压缩）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 spec §10 P2 行：MemoryTools 三工具 + 自动提取管线（触发/去抖/去重）+ 会话压缩摘要 + 提取设置项；并清偿 P1 终审 backlog 前三项。

**Architecture:** agent 工具走既有 ToolModule 插槽（子进程内 WAL 写库，P1 已验证）；提取管线在主进程以 session-naming 范本（leader 成员 provider 链 + fire-and-forget 全 catch）运行；会话压缩是同一提取 LLM 调用的第二产出（spec §6.4）。设计全文：`docs/specs/2026-09-03-v2.2-agent-memory-design.md` §6.2/§6.4/§7.3。

**Tech Stack:** 同 P1（Electron CJS / better-sqlite3 WAL / @node-rs/jieba / Vitest）。

## Global Constraints（与 P1 相同，逐条继承）

- Node 20（`nvm use 20`，容器默认 26 会毁 better-sqlite3）；`npx pnpm@9.0.0`
- 主进程 CJS；strict TS（禁 `any`/`@ts-ignore`/`as any`）；注释全中文；Conventional Commits 中文；单测只放 `electron/tests/**`（renderer 贴源）；`GIT_MASTER=1 git` 提交
- **既有契约冻结**：MemoryProvider 接口签名、memory:* IPC 五通道、memories 表 schema 不变（只允许追加式扩展）
- 提取管线铁律（spec §8）：**绝不阻塞会话/任务主链路**——fire-and-forget + 全 catch + logger 降级
- 测试保真（momo-test-rules）：provider 用真实 SQLite（AP_USER_DATA_DIR 夹具）或 `__setMemoryProviderForTest` 注入真实实现；LLM mock 只 mock `chat()` 返回值

## P1 遗产（本计划依赖的已验证接口）

- `repo.ts`：`insertMemory/updateMemory/deleteMemory/listMemories(scope, filter)/touchMemoryUsed`，`SaveMemoryInput`（pinned 缺省按 kind 推导）
- `search.ts`：`searchMemories(query, {workspaceId, sessionId|null}, limit)`
- `provider`：`getPinnedContext/searchMemories/saveMemory/deleteMemory`（searchMemories 命中自动 touch use_count）
- `injection.ts`：`buildPinnedView(PinnedParts)`，预算 2000/3000/1000/1000
- `session-naming.ts`：主进程 LLM 范本——`findReceptionAgent(sessionId)` JOIN 取 leader 的 instanceId+agentDefinitionId → `getAgentDefinition` → `getProvider` → `resolveApiKey(instanceId, providerId)` → `createLLMProvider({provider, model, baseUrl}, apiKey)` → `llm.chat()`
- runtime 工具：`ToolModule`（getDefs/handles/execute）+ `buildToolRegistry` 注册中心；动态工具名自动并入 `config.allowedTools`（runtime-entry 既有逻辑）

### Task 3: 提取管线核心 + 会话压缩（spec §6.4）

**Files:**
- Create: `electron/src/main/memory/extraction.ts`
- Test: `electron/tests/memory/extraction.test.ts`

**Interfaces:**
- `export async function runExtraction(sessionId: string, opts?: {taskId?: string | null}): Promise<void}` —— 主入口；导出供触发接线与测试
- `export function scheduleExtraction(sessionId: string, opts?): void` —— fire-and-forget 包装（void + catch + logger.warn，复刻 scheduleLlmTitle 模式）
- `export const EXTRACTION_DEBOUNCE_MS = 10 * 60 * 1000`；`export const SESSION_COMPRESS_THRESHOLD = 40`；`export const TRIGGER_TURN_INTERVAL = 20`（供接线与测试引用）
- 内部：模块级 `Map<sessionId, lastRunAt>` 去抖；`resolveSessionLlm(sessionId)` 复刻 session-naming 的 findReceptionAgent→provider→resolveApiKey 链（解析失败返回 null → 本轮跳过 + warn）

**行为（ADD-only，spec §6.4 逐条）：**
1. Gate：`getGlobalSettings().memoryEnabled && memoryExtractionEnabled`（后者 Task 5 加入，本任务先读 `?? true`）任一 false → 直接返回
2. 去抖：10 分钟内同会话已跑 → 跳过
3. 窗口：`getConversationContext(sessionId, {limit: 50})`；用户消息 <2 条 → 跳过
4. LLM：一次 `chat()` 调用，system prompt 要求只输出 JSON：`{"memories":[{"kind":"preference|knowledge|summary","content":"...","tags":[...]}], "session_summary":"..."（仅当会话总消息数>40 时要求）}`；明确指示「只提取新信息，不做更新/删除」
5. 解析容错：坏 JSON 逐对象扫描（从文本中提取首个 `{...}` 平衡块再 JSON.parse，失败则逐行扫描 `"kind":` 对象）；可解析条目过 `kind` 白名单校验
6. 去重：每候选与同 scope 既有记忆 `searchMemories(content 前 40 字)`（scope={workspaceId, sessionId:null}——自动提取不落 session 层，spec：偏好/知识进 global/workspace 由 LLM 判定？**裁定：候选带 scope 字段 'global'|'workspace'，白名单校验，缺省 workspace**）；BM25 有命中（结果数>0 且首条内容与候选高度重叠——简化：首条 content 包含候选前 20 字或反之）→ 跳过 + 日志
7. 落库：`insertMemory({source:'auto', pinned:0, confidence:0.7, tags})`
8. 会话压缩：总消息数 >40 且 LLM 返回 session_summary 非空 → 覆盖 upsert `session_summaries`（summary=新总结全文——prompt 要求「融合既有摘要」（窗口里没有旧摘要，把旧 summary 一并放进 prompt 输入）+ covered_until=窗口最新消息 createdAt）；≤40 不写
9. 完成后 logger.info 计数（提取 N 条 / 跳过 M 条 / 压缩 yes|no）

**Steps（TDD，mock LLM chat 返回值）：**
- [ ] 失败测试：ADD-only 落库 / 坏 JSON 容错 / 去重跳过 / 双开关 gate / 去抖窗口 / >40 压缩 upsert+游标推进 / ≤40 不写摘要 / provider 解析失败静默跳过
- [ ] 实现 → 全绿 + tests/memory/ 回归 + typecheck → 提交 `feat(memory): 自动提取管线——ADD-only/去重/会话压缩（v2.2 记忆 P2）`
