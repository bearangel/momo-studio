### Task 2: 导出/导入 Markdown（spec §7.2/§10）

**Files:** `electron/src/main/memory/ipc.handlers.ts`（+2 通道）、`electron/src/main/storage/memories/repo.ts`（如需批量插入辅助）、`electron/src/preload/index.ts`、`renderer/src/ipc/types.d.ts`、`renderer/src/components/settings/MemorySettings.tsx`
**契约：**
- `memory:exportMarkdown(scope) → {filename, content}`——格式：`# 记忆导出（层名）\n日期\n\n## [kind|source|pinned] content\n- tags…`（人类可读 + 可再导入）
- `memory:importMarkdown(scope, content) → {imported, skipped}`——逐 `## ` 段解析 [kind|source|pinned] 头 + 正文；source 固定 'user'（导入即用户资产）；格式不符段 skipped 计数；同 scope 去重（复用 Task 1 的无 touch 检索）
- UI：列表头部「导出 / 导入」按钮——导出走既有 Blob 下载模式（参照 session.exportMessages 消费端）；导入用文件选择（renderer File API 读文本后 invoke）
- renderer 镜像类型 + preload 三方对齐（通道名/invoke 串/方法签名逐字）
**Steps（TDD）:** 导出往返测试（export→import 同库断言条目复原/格式头解析/坏段 skipped/source='user'）→ UI 测试（按钮→调用）→ 双端 typecheck → 提交 `feat(memory): 记忆导出/导入 Markdown（v2.2 记忆 P3）`
