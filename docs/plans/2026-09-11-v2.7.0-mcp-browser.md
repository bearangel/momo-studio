# v2.7.0 McpBrowser 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 12 个 agent 浏览器工具 + 主窗口右侧 WebContentsView 实时预览 sidebar（Electron 原生架构，零新重依赖）。

**Architecture:** BrowserManager（main 单例）管理 per-workspace WebContentsView tabs（`persist:browser-<wsId>` partition 隔离 + 跨重启登录态）；agent 工具与用户共用同一「当前 tab」（takeover 状态机仲裁）；sidebar chrome 属 renderer，页面内容属 main（占位区 rect 同步 bounds）。

**Tech Stack:** Electron 30 WebContentsView / webContents.debugger（CDP 子集）/ session partition / net.connect 探活。**无新第三方依赖**。

**Spec:** `docs/specs/2026-09-11-mcp-browser-design.md`（v0.2）——实现疑义一律以 spec 为准。
