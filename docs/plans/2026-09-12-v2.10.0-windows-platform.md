# v2.10.0 Windows 全平台化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows 代码层硬化与打包就绪——路径语义 helper + 五模块采用 + MCP spawn 修正 + 单实例锁 + NSIS 加固；Linux 容器内用 `vi.mock path.win32` 锁住 Windows 路径语义。

**Tech Stack:** Node `path.win32`（模拟测试语义基准）；`vi.mock('node:path')`。无新依赖。

**Spec:** `docs/specs/2026-09-12-windows-platform-design.md`——实现疑义以 spec 为准。

### Task 1: platform/paths.ts helper + win32 测试基建

**Files:**
- Create: `electron/src/main/platform/paths.ts`
- Test: `electron/tests/platform/paths.test.ts` + `electron/tests/platform/paths.win32.test.ts`

**Interfaces:**
- Produces:
```typescript
export function isInsideDir(root: string, child: string): boolean;
// child === root → true；两侧 path.resolve 归一；win32 下大小写不敏感前缀比对
//（含 path.sep 边界，'..foo.txt' 不误伤）；纯函数不触 fs；非法输入返回 false
export function toPosixRelPath(root: string, absPath: string): string;
// path.relative(root, absPath) 后统一 '/'（不以裸 split(path.sep) 实现）
```

- [ ] **Step 1**: 失败测试 `paths.test.ts`（posix 原生）：等价断言——对每组 (root, child)，`isInsideDir` 与既有手工形态 `resolve(child).startsWith(resolve(root)+sep) || equal` 结果一致（随机/边界组合表驱动）；`toPosixRelPath('/ws', '/ws/a/b') === 'a/b'`；child===root true；`..foo.txt` 不误伤；空串 false
- [ ] **Step 2**: 失败测试 `paths.win32.test.ts`（vi.mock 模板头，落文件头注释供 T2 复制）：
  - `'C:\\WS'` vs `'c:\\ws\\proj\\a.txt'` → true（大小写）
  - `'\\\\srv\\share\\ws'` vs UNC 子路径 → true；`'C:\\other\\x'` vs `'c:\\ws'` → false（异盘）
  - `'C:\\ws\\..foo.txt'` → true（前缀不误伤）；`'C:\\ws'` 自身 true
  - `toPosixRelPath('C:\\ws', 'C:\\ws\\a\\b')` === `'a/b'`
- [ ] **Step 3**: 实现（isInsideDir：`resolve` 两侧 + `process.platform === 'win32' ? toLowerCase 比对 : 严格比对`；注意 **mock path 后 process.platform 仍是 linux**——win32 大小写分支需以「被 mock 的 path 对象是否为 win32 实现」或显式注入判定，实现取 **可选第三参 `opts?: { win32?: boolean }`** 默认 `process.platform === 'win32'`，win32 测试传 `true`——注释说明）→ GREEN
- [ ] **Step 4**: 全绿 + typecheck；Commit：`feat(platform): paths 共享 helper——isInsideDir win32 感知 + toPosixRelPath`
