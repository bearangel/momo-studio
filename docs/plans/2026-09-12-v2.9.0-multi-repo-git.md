# v2.9.0 多仓 git 工具 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** workspace 内层仓对 agent 可见可操作——`git_repos` 发现工具 + 既有 9 个 git 工具可选 `repo` 参数（缺省根仓零变化）。

**Architecture:** `discoverRepos` 从 `journal/detector.ts` 纯搬家上提 `git/repos.ts` 共享；git-tools 加 `resolveRepoPath`（wsFs 边界 + 命中发现列表）+ `runGit` 第四参 `repoPath`（`-C` 前置）；GitPolicy 均匀继承（分支保护按目标仓当前分支匹配）；v2.5 账本零改动。

**Tech Stack:** 纯 TypeScript；真 tmp git 仓 fixture。无新依赖。

**Spec:** `docs/specs/2026-09-12-multi-repo-git-design.md`——实现疑义以 spec 为准。

## Global Constraints

- Node 20：容器内先 `export PATH="/home/ai-agent/.nvm/versions/node/v20.20.2/bin:$PATH"`；`npx pnpm@9.0.0`
- TypeScript strict + `noUncheckedIndexedAccess`；禁 `any` / `@ts-ignore` / `as any` / `// eslint-disable`
- 注释/文档全中文；标识符英文；Conventional Commits
- electron 单测集中 `electron/tests/`（镜像 src/）；typecheck 含 tests/ 门禁
- **缺省零变化是硬门**：不传 repo 的全部既有 git 工具测试零回归；detector 对账语义零漂移
- momo-test-rules：真 git 仓 fixture（`git init` + commit + dirty）；错误路径专项；接线锁红绿变异
- 每个 task 独立 commit
