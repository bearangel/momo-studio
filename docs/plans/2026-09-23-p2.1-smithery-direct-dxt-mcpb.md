# P2.1 Smithery 直连安装 + DXT/MCPB 导入 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Smithery hosted 条目免账号直连安装（deploymentUrl + 用户 config → 远程 MCP）+ 分页加载 + DXT/MCPB 本地包导入；魔搭轨整体移除。

**Architecture:** 复用 P2 streamableHttp 全链（HttpMcpClient/二态注册）；安装流改造为两态（needsConfig 弹窗 / 直装）；bundle 导入复用 adm-zip 基建落 `mcp-bundles/{slug}` + `cwd` spawn 支持（migration 039）。

**Tech Stack:** Electron 主进程（CommonJS）+ React renderer；adm-zip（既有依赖）；零新 npm 依赖。

**Spec:** `docs/specs/2026-09-23-p2.1-smithery-direct-dxt-mcpb-design.md`（决策 D1-D8 以 spec 为准）

## Global Constraints

- **Node 20 强制**：每次跑测试前 `source ~/.nvm/nvm.sh && nvm use 20` 且验证 `node -v`=v20（Node 26 → better-sqlite3/jsdom 假红）
- 包管理器 `npx pnpm@9.0.0`；双 workspace typecheck：`cd /workspace && npx pnpm@9.0.0 typecheck`
- TypeScript strict：禁 `any` / `as any` / `@ts-ignore`
- 注释全中文；文件尾换行；Conventional Commits
- renderer 新 UI 只用语义 token；禁 emoji 图标（lucide-react 16px/stroke 1.75）；测试 colocated（renderer）/集中 `electron/tests/`
- IPC 契约两端同步（electron types ↔ renderer types.d.ts ↔ preload；momo-boundary-rules）
- Smithery URL 拼接一律 `encodeURIComponent(qualifiedName)`；`item.slug` 禁止直接拼文件路径
