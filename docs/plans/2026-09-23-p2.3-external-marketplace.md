# P2.3 移除网络获取 + 外部市场快捷打开 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** renderer 移除资源页「网络获取」模式，换成工具栏「外部市场」快捷打开（浏览器跳转）+ AddMenu「启用预置库」；electron 现有管线零改动（仅两个小新增通道）。

**Architecture:** 删 RegistryBrowse/Segmented/McpConnectDialog 及 registry 安装接线（store 双态收敛单态）；新增 ExternalMarketplacePopover（清单常量 + openExternal）与 PresetLibraryDialog（本地 YAML 只读清单 → 现有 EnablePresetDialog）；electron 加 `resource:listBuiltinPresets` 与 `misc:openExternal`（若 Task 0 发现已存在则复用）。

**Tech Stack:** Electron 主进程（CommonJS）· React + zustand（语义 token / components/ui 原子组件 / lucide 16px stroke 1.75）· vitest 双 workspace

**Spec:** `docs/specs/2026-09-23-p2.3-external-marketplace-design.md`（D1-D7 决策为准）
