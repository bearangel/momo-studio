## 2. 项目列表

### 批次 A：后端修复（electron 侧）

#### A1：keychain slot helper 去重

**位置**：`electron/src/main/agent/ipc.handlers.ts:38-39` + `electron/src/main/agent/crud.ts:161-164`

**问题**：两个等价函数 `llmApiKeyStorageKey`（ipc.handlers 私有）和 `llmApiKeyRef`（crud 导出），生成同样的 key `agent.<instanceId>.llm_api_key`。

**改法**：删 `llmApiKeyStorageKey`，3 处调用（ipc.handlers.ts:121, 259, 449）改 import `llmApiKeyRef`。

#### A2：modelBaseUrl undefined→'' 往返保真

**位置**：`electron/src/main/agent/crud.ts:186`

**问题**：`updateAgentDefinition` 中 `const newBaseUrl = input.modelBaseUrl !== undefined ? input.modelBaseUrl : (existing.model.baseUrl ?? '')`。原值 NULL + 不传 → 写 `''` 而非 `NULL`，语义漂移。

**改法**：`?? ''` → `?? null`。补测试覆盖原 NULL 不传 → 仍 NULL。

#### A3：stopRunningInstancesByDefinition 补测

**位置**：`electron/tests/agent/crud-update.test.ts`

**问题**：mock 锁死 `isAgentRunning: () => false`，实际停止分支（true 路径）从未被测。

**改法**：mock 改动态 `vi.mocked(isAgentRunning).mockImplementation(...)`，加 3 case（全 true / 全 false / 混合）。

#### A4：协调 agent 设定后自动重启

**位置**：`electron/src/main/workspace/ipc.handlers.ts`（setCoordinator handler）

**问题**：UI 弹 alert 提示"请手动停止后重新启动"，体验差。

**改法**：setCoordinator handler 内：若目标 instance 正在运行 → stop → 从 keychain 恢复 token/apiKey → spawn。UI 删 alert 提示，改为成功后静默刷新。

### 批次 B：前端修复（renderer 侧）

#### B1：文件树折叠状态 localStorage 持久化

**位置**：`renderer/src/stores/file.store.ts`

**问题**：`expandedDirs` 仅内存 Set，切换 workspace / 刷新页面 / 重启后丢失。

**改法**：
- store 初始化时从 `localStorage.getItem('fileTree.expanded.<workspaceId>')` 读 JSON 数组
- `toggleDir` / `collapseAll` 同步写回
- workspaceId 隔离避免跨工作区污染

#### B2：setCoordinator + file CRUD 异常处理一致化

**位置**：`renderer/src/stores/workspace.store.ts:59-64` + `renderer/src/stores/file.store.ts:79-98`

**问题**：`setCoordinator` 无 try/catch（失败不记录 error）；file CRUD 三个动作裸 await 无 error 处理。与 `agent.store.ts` 的 `set error / catch / throw` 模式不一致。

**改法**：
- workspace.store `setCoordinator`：加 try/catch + set error + throw
- file.store `createPath` / `deletePath` / `renamePath`：加 try/catch + set error + throw
- 调用方（FileTree / FileTreeView）加 `.catch(alert)` 或监听 store.error

#### B3：M3 gap — 编排视图折叠/展开

**位置**：`renderer/src/components/agent/AgentOrchestrator.tsx`

**问题**：M3 编排视图 main 节点总是展开子列表，无法折叠。

**改法**：加 `collapsedMains: Set<string>` state，main 节点标题加 ▸/▾ 切换按钮。

#### B4：M3 gap — 重复安装守卫 + 孤儿子 agent 可见性

**位置**：`electron/src/main/agent/ipc.handlers.ts`（assignMainAgent）+ `renderer/src/components/agent/AgentOrchestrator.tsx`

**问题**：
- 对已安装的 main 再次 `assignMain` 会尝试重复注册 bot
- sub 定义单独 `addToWorkspace` 后在编排视图无处显示（parent 不在 workspace 内）

**改法**：
- `assignMainAgent` 开头检查 mainDef 是否已有 assignment → throw"已安装，请先移除"
- AgentOrchestrator 增加"未分组"区域，展示 `parentAgentId` 非空但 parent 未安装的 sub

### 批次 C：基建

**改法**：删 `.gitignore` 中裸 `docs` 行。已有的 `.superpowers/sdd/` 等具体条目不受影响。

#### C2：CHANGELOG.md + 版本号规范
