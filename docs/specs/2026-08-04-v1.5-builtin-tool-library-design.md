# v1.5 — 内置工具库设计

**版本**：v1.5.0
**作者**：Sisyphus（基于 brainstorming 会话产出）
**日期**：2026-08-04
**状态**：待 review

## 1. 背景

v1.4 之前的内置工具仅 3 个：`read_file` / `write_file` / `list_files`。agent 完成常见编程任务的能力严重不足——无法跑测试、无法增量编辑、无法搜索代码库、无法看类型错误、无法抓文档。

opencode、Claude Code 等现代 agent 工具的经验表明：丰富的内置工具集是 agent 生产力的基础。

v1.5 系统性补全内置工具库，覆盖 7 个能力域，达到对标 opencode 的水平。

## 2. 目标

让 Momo Studio 的 declarative agent（Matrix bot）在 workspace 内：

- 跑命令、装依赖、跑测试、跑构建
- 增量编辑代码（不必每次重写整个文件）
- 在大代码库内高效搜索内容与文件
- 看类型错误、找符号引用
- 抓取外部文档
- 维护任务列表跟踪进度
- 完成本地版本控制闭环

## 3. 非目标

- 不做 websearch（v1.5 仅 webfetch）
- 不做 LSP 的 goto_definition / rename / quickfix（仅 diagnostics + find_references）
- 不接 ESLint（仅 tsserver 自带语义/类型诊断）
- 不做 headless 浏览器（v1.5 用静态 HTML→Markdown 转换）
- 不做 Git push / merge / reset（保留给人）
- 不做 Skill marketplace 或 MCP marketplace

## 4. 关键决策汇总

| 维度 | 决策 | 理由 |
|---|---|---|
| 工具范围 | 全栈对标 opencode（7 类共 23 个工具） | 一次性铺到位，避免后续频繁补丁 |
| Bash 安全 | workspace 内自由 shell + 黑名单 | 跟 opencode/Claude Code 一致，体验最好 |
| 网络 | 完全开放 | 跟自由 shell 配套 |
| edit_file | str_replace 风格（唯一匹配强制） | LLM 接受度最高，错误时回写文件头自我纠正 |
| Git 工具 | 本地读写集（status/diff/log/show/add/commit/branch/checkout/stash，不含 push/merge/reset） | 覆盖 90% agent 编码场景，不可逆操作留给人 |
| Todo | 会话级 store + UI 实时可见 + Matrix 持久化 + 重启还原 | 进度可视化 + 历史可回溯 |
| LSP | 轻量（TS/JS only，仅 diagnostics + find_references） | 高频两件套，其他能力留到 v1.6+ |
| Web | 仅 webfetch（不做 websearch） | 零额外 API key 配置 |
| grep/glob | Node + fast-glob + ignore 包，无 ripgrep 二进制 | Electron 打包友好 |
| .gitignore | 自动加载 + mtime 缓存 | 跟用户对仓库认知一致，避免搜依赖产物 |

### 5.2 ToolModule 接口

每个工具模块统一实现这个接口：

```typescript
// tools/types.ts
export interface ToolContext {
  wsFs: WorkspaceFS;          // workspace 文件沙箱（已有）
  workspaceId: string;        // 🆕 git/lsp/workspace 级 store 需要
  workspaceDir: string;       // 🆕 bash/git/lsp 的 cwd
  skillRegistry: SkillRegistry;  // 已有
  streamSessionId: string;    // 🆕 todo store 索引
  parentStreamSessionId?: string;  // 🆕 子 agent todo 嵌套（v1.4 dispatch UUID 复用）
  roomId: string;             // 🆕 StreamChunk 推送
  sendStreamChunk: (chunk: StreamChunk) => void;  // 🆕 todo/stream 推送
}

export interface ToolModule {
  /** 该模块提供的工具定义，喂给 LLM */
  getDefs(): LLMToolDef[];
  /** 执行单个工具调用 */
  execute(name: string, args: Record<string, unknown>, ctx: ToolContext): Promise<string>;
  /** 判断工具名是否属于本模块（路由用） */
  handles?(name: string): boolean;
}
```

```typescript
// tools/index.ts
export function buildToolRegistry(ctx: ToolContext): ToolModule[] {
  const modules: ToolModule[] = [
    new FileTools(),
    new SearchTools(),
    new ShellTools(),
    new GitTools(),
    new WebTools(),
    new TodoTools(),
  ];
  // LSP 条件注册
  const lsp = LspTools.create(ctx);
  if (lsp) modules.push(lsp);
  return modules;
}

export async function executeTool(
  name: string,
  args: Record<string, unknown>,
  ctx: ToolContext,
  modules: ToolModule[],
): Promise<string> {
  // 权限校验（白名单 + 黑名单 + 通配符）
  assertToolAllowed(name, ctx.permissionConfig);

  for (const m of modules) {
    if (m.handles?.(name)) {
      return m.execute(name, args, ctx);
    }
  }
  throw new UnknownToolError(name);
}
```

#### edit_file 语义

```typescript
async executeEditFile(args, ctx) {
  const filePath = parseStringArg(args.path, 'path');
  const oldStr = parseStringArg(args.oldString, 'oldString');
  const newStr = parseStringArg(args.newString, 'newString');

  if (oldStr === newStr) throw new Error('oldString 与 newString 相同，无操作');

  const abs = ctx.wsFs.assertInWorkspace(filePath);
  if (!fs.existsSync(abs)) throw new Error(`文件不存在: ${filePath}`);

  const original = await fs.promises.readFile(abs, 'utf-8');

  // 唯一性匹配
  const firstIdx = original.indexOf(oldStr);
  if (firstIdx === -1) {
    // 失败时回写文件头 500 字符，让 LLM 自我纠正
    const preview = original.slice(0, 500);
    throw new Error(`oldString 未在文件中找到。文件开头 500 字符:\n${preview}`);
  }
  const lastIdx = original.lastIndexOf(oldStr);
  if (firstIdx !== lastIdx) {
    throw new Error(`oldString 在文件中出现多次（${original.split(oldStr).length - 1} 处），请提供更长上下文以唯一定位`);
  }

  const updated = original.slice(0, firstIdx) + newStr + original.slice(firstIdx + oldStr.length);
  await fs.promises.writeFile(abs, updated, 'utf-8');

  const beforeLines = original.slice(0, firstIdx).split('\n');
  const startLine = Math.max(0, beforeLines.length - 2);
  return `已编辑 ${filePath}（第 ${startLine + 1} 行附近）`;
}
```

**关键决策**：
1. 唯一匹配强制——多重匹配直接报错，逼 LLM 提供更长上下文
2. 失败时回写文件头——LLM 看到实际内容，下轮基于真实文本重新生成 oldString
3. 空 oldString 拒绝——不做 insert 语义，避免误用

#### .gitignore 集成

```typescript
import ignore from 'ignore';

const gitignoreCache = new Map<string, { mtime: number; matcher: ignore.Ignore }>();

function loadGitignore(workspaceDir: string): ignore.Ignore | null {
  const gitignorePath = path.join(workspaceDir, '.gitignore');
  if (!fs.existsSync(gitignorePath)) return null;

  const stat = fs.statSync(gitignorePath);
  const cached = gitignoreCache.get(workspaceDir);
  if (cached && cached.mtime === stat.mtimeMs) return cached.matcher;

  try {
    const content = fs.readFileSync(gitignorePath, 'utf-8');
    const matcher = ignore().add(content);
    gitignoreCache.set(workspaceDir, { mtime: stat.mtimeMs, matcher });
    return matcher;
  } catch {
    return null;  // 解析失败静默降级
  }
}

// 在 grep/glob 流程中：
const candidates = await fastGlob(includeGlob, {
  cwd: absStart,
  ignore: ['**/node_modules/**', '**/.git/**', '**/dist/**', '**/build/**'],
  nodir: true,
});

// 用 .gitignore 二次过滤
const ig = loadGitignore(ctx.workspaceDir);
const filtered = ig ? candidates.filter((p) => !ig.ignores(p)) : candidates;
```

**关键决策**：
1. 零外部二进制依赖——Node + fast-glob + ignore 包，Electron 友好
2. 默认 ignore 硬编码 `node_modules/.git/dist/build`（不依赖 .gitignore 存在）
3. .gitignore 按 mtime 缓存，编辑后自动失效
4. 路径沙箱双重校验——起始目录过 `assertInWorkspace`，候选文件再过一次（防 symlink 逃逸）
5. 上限：grep 50 条 / glob 200 条，超限给"缩小范围"提示
6. 超长行截断（200 字符），单文件 1MB 跳过

#### 执行流程

```typescript
async function executeBash(args, ctx) {
  const command = parseStringArg(args.command, 'command');
  const timeoutMs = clamp(typeof args.timeoutMs === 'number' ? args.timeoutMs : 30000, 1000, 120000);

  assertCommandAllowed(command);  // 黑名单拦截

  const env = buildSandboxEnv(ctx);
  const shell = process.platform === 'win32' ? 'cmd.exe' : '/bin/bash';
  const shellArgs = process.platform === 'win32' ? ['/c', command] : ['-c', command];

  return await new Promise((resolve) => {
    const child = spawn(shell, shellArgs, {
      cwd: ctx.workspaceDir,
      env,
      stdio: ['ignore', 'pipe', 'pipe'],
      windowsHide: true,
    });

    const STDOUT_MAX = 10 * 1024;
    const STDERR_MAX = 10 * 1024;
    let stdout = '';
    let stderr = '';
    let truncated = false;
    let killed = false;

    child.stdout.on('data', (chunk) => {
      if (stdout.length >= STDOUT_MAX) { truncated = true; return; }
      stdout += chunk.toString('utf-8').slice(0, STDOUT_MAX - stdout.length);
    });
    child.stderr.on('data', (chunk) => {
      if (stderr.length >= STDERR_MAX) { truncated = true; return; }
      stderr += chunk.toString('utf-8').slice(0, STDERR_MAX - stderr.length);
    });

    const timer = setTimeout(() => {
      killed = true;
      child.kill('SIGKILL');
    }, timeoutMs);

    child.on('close', (code) => {
      clearTimeout(timer);
      const parts = [`exit_code: ${code ?? 'null'}`];
      if (killed) parts.push(`(超时 ${timeoutMs}ms，已强杀)`);
      if (stdout) parts.push(`stdout:\n${stdout}${truncated ? '\n…(stdout 已截断)' : ''}`);
      if (stderr) parts.push(`stderr:\n${stderr}${truncated ? '\n…(stderr 已截断)' : ''}`);
      if (!stdout && !stderr && code === 0) parts.push('(无输出)');
      resolve(parts.join('\n\n'));
    });

    child.on('error', (err) => {
      clearTimeout(timer);
      resolve(`shell 启动失败: ${err.message}`);
    });
  });
}
```

#### 沙箱环境变量

```typescript
function buildSandboxEnv(ctx) {
  const ALLOWED = new Set([
    'PATH', 'HOME', 'USER', 'USERPROFILE',
    'LANG', 'LC_ALL', 'LC_CTYPE',
    'SHELL', 'TERM',
    'TMPDIR', 'TMP', 'TEMP',
    'SYSTEMROOT', 'WINDIR',
  ]);

  const env = {};
  for (const key of Object.keys(process.env)) {
    if (ALLOWED.has(key)) env[key] = process.env[key];
  }

  env.WORKSPACE_DIR = ctx.workspaceDir;
  env.MOMO_STUDIO_AGENT = '1';

  // 显式不传：API keys、token、密钥
  return env;
}
```

**关键决策**：
1. cwd 锁定 workspace 根，cd 不持久（每条命令独立 shell）
2. 退出码非 0 不抛错——LLM 看 stderr 自我纠正
3. 超时强杀进程树（`SIGKILL`，spawn 在同 process group）
4. stdout/stderr 各 10KB 截断
5. 白名单环境变量——不传 API key/token（关键安全防线）
6. 黑名单保守——只拦灾难性命令 + `git commit`（强制走 git_commit 工具）
7. Linux/macOS 用 `/bin/bash`；Windows 暂用 `cmd.exe`（PowerShell 留 v1.6+）
8. 完全开放网络（npm install / pip install / curl 都允许）

#### git_commit 走 GitPolicy

```typescript
async function executeGitCommit(args, ctx) {
  const message = parseStringArg(args.message, 'message');
  const description = typeof args.description === 'string' ? args.description : undefined;

  const policy = getGitPolicy(ctx.workspaceId);

  // 1. 总开关
  if (!policy.allowAgentCommits) {
    throw new Error('GitPolicy 禁止 agent 自动提交（allowAgentCommits=false）');
  }

  // 2. 当前分支保护
  const { stdout: branchOut } = await runGit(['rev-parse', '--abbrev-ref', 'HEAD'], ctx);
  const currentBranch = branchOut.trim();
  if (currentBranch === policy.defaultBranch) {
    const fallback = renderFallbackBranch(policy.fallbackBranchPattern, ctx);
    await runGit(['checkout', '-b', fallback], ctx);
  }

  // 3. message pattern 校验（复用现有 commit-validator.ts）
  const validation = validateCommitMessage(message, policy.commitMessage);
  if (validation.severity === 'error') {
    throw new Error(`commit message 不合规: ${validation.reason}\n期望格式示例: ${policy.commitMessage.patterns.map(p => p.example).join(' / ')}`);
  }

  // 4. 拼最终 message（含 trailers）
  const finalMessage = renderCommitMessage(message, description, policy.commitMessage);

  // 5. 实际提交
  const result = await runGit(['commit', '-m', finalMessage], ctx);
  if (result.code !== 0) throw new Error(`git commit 失败: ${result.stderr}`);

  if (validation.severity === 'warning') {
    return `${result.stdout}\n⚠️ GitPolicy warning: ${validation.reason}`;
  }
  return result.stdout;
}
```

#### URL 规范化

```typescript
function normalizeUrl(raw) {
  let parsed;
  try {
    parsed = new URL(raw);
  } catch {
    throw new Error(`非法 URL: ${raw}`);
  }

  if (parsed.protocol === 'http:') {
    parsed.protocol = 'https:';  // 强制升级
  }

  if (parsed.protocol !== 'https:') {
    throw new Error(`不允许的协议: ${parsed.protocol}（仅 http/https）`);
  }

  return parsed.toString();
}
```

#### HTML 转换

```typescript
import TurndownService from 'turndown';
import * as cheerio from 'cheerio';

const turndown = new TurndownService({
  headingStyle: 'atx',
  codeBlockStyle: 'fenced',
  bulletListMarker: '-',
  emDelimiter: '_',
});
turndown.remove(['script', 'style', 'nav', 'footer', 'header', 'aside', 'noscript']);

function htmlToMarkdown(html) {
  return turndown.turndown(html).trim();
}

function extractBySelector(html, selector) {
  const $ = cheerio.load(html);
  const $el = $(selector).first();
  if ($el.length === 0) {
    throw new Error(`CSS 选择器 "${selector}" 未匹配到元素`);
  }
  return $el.html() ?? '';
}
```

**关键决策**：
1. HTTP 强制升级 HTTPS（避免明文 + 现代 Web 主流）
2. 仅 http/https 协议——拦截 `file://` / `data:` / `ftp:`
3. 不引 headless 浏览器——v1.5 用 turndown 静态转换；SPA 留 v1.6+
4. 4xx/5xx 不抛错——让 LLM 看 status 自处理
5. 双阶段截断：fetch 100KB + 转换后 50KB
6. selector 提取——高频用例是"我只要文章正文"
7. 超时上限 60s
8. UA 标识 `MomoStudio-Agent/1.5`——不伪装
9. 不解析 robots.txt——v1.5 简化，靠 systemPrompt 教 LLM 自律
10. 新依赖：turndown + cheerio（纯 JS、Electron 友好）

```typescript
// renderer/src/components/im/TodoSection.tsx
function TodoSection({ todos, isStreaming }) {
  const [expanded, setExpanded] = useState(isStreaming);
  useEffect(() => {
    if (!isStreaming) setExpanded(false);  // 完成自动折叠
  }, [isStreaming]);

  if (todos.length === 0) return null;

  const doneCount = todos.filter(t => t.completed).length;
  const progressPct = Math.round((doneCount / todos.length) * 100);

  return (
    <div className="todo-section">
      <button onClick={() => setExpanded(!expanded)}>
        📋 任务 {doneCount}/{todos.length}（{progressPct}%） {expanded ? '▼' : '▶'}
      </button>
      {expanded && (
        <ul>
          {todos.map((t, i) => (
            <li key={t.id} className={`todo-${t.status}`}>
              <span>{t.status === 'completed' ? '✓' : t.status === 'in_progress' ? '▶' : '○'}</span>
              <span className={t.status === 'completed' ? 'line-through opacity-60' : ''}>
                {i + 1}. {t.subject}
              </span>
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}
```

#### 条件注册

```typescript
function shouldRegister(workspaceDir: string): boolean {
  if (fs.existsSync(path.join(workspaceDir, 'tsconfig.json'))) return true;
  if (fs.existsSync(path.join(workspaceDir, 'jsconfig.json'))) return true;
  try {
    const entries = fs.readdirSync(workspaceDir, { withFileTypes: true });
    return entries.some((e) => e.isFile() && (e.name.endsWith('.ts') || e.name.endsWith('.js')));
  } catch {
    return false;
  }
}
```

#### LspManager 单例（per workspace）

- 懒启动：首次调 lsp_* 才 spawn `typescript-language-server --stdio`
- JSON-RPC over stdio，Content-Length 头解析
- per-workspace 单例（多 agent 共享）
- 5 分钟闲置自动 shutdown
- content hash 同步（内容没变跳过 didChange）
- 0-based line（LSP 协议）↔ 1-based line（工具接口）转换
- 上限：诊断 50 条 / 引用 50 条

**关键决策**：
1. 仅 TS/JS（最常见、Electron 项目自身 Node）
2. typescript-language-server（基于 LSP 标准，不是 tsserver 私有协议）
3. 懒启动 + 5 分钟闲置 shutdown——节省 ~200MB tsserver 内存
4. per-workspace 单例——避免重复 spawn
5. 不暴露 goto_definition / rename / quickfix——v1.5 只做最高频两件套
6. LLM 滥用对策：tool-permission 黑名单 + systemPrompt 教 LLM 只在重要改动后调

## 9. 错误处理统一原则

| 错误类型 | 行为 | LLM 看到 |
|---|---|---|
| 参数缺失/类型错 | 抛 Error | 错误 message（自我纠正线索） |
| 路径越界 | 抛错（WorkspaceFS 原文） | 路径越界错误 |
| 文件不存在 | 抛错（`文件不存在: X`） | 自纠正（先 list_files） |
| 命令黑名单 | 抛错（含 reason） | 知道哪类禁止 |
| 网络失败/超时 | 抛错（含毫秒数） | 改 URL 或重试 |
| 工具内部异常 | 抛错（原始 message） | 看到根因 |
| 退出码非 0 / HTTP 4xx | **不抛错** | 返回 status 让 LLM 排查 |
| 路径不存在但语义合理 | **不抛错** | 如 exists 返回 "不存在" |

所有抛出的 Error 都被 `runtime-entry.executeTool` 的 try/catch 捕获，转成 tool_result content + 触发审计日志（`success: false`）。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| LSP server 启动慢拖累首轮响应 | 懒启动 + 1s 等待兜底返回缓存 |
| bash 子进程孤儿（agent 中断） | abort 时强制 `kill -SIGKILL` 整个进程组 |
| todo Store 内存泄漏（会话累积） | 会话结束（sendFinalMessage）后清理 + 5 分钟 idle GC |
| git commit 走 GitPolicy 但 agent 绕过用 bash | bash 命令黑名单加 `git commit` 模式 |
| LLM 滥用 bash 跑测试爆量输出 | 默认 10KB 截断 + systemPrompt 教学 |
| typescript-language-server 版本与 TypeScript 不匹配 | package.json peer dep 锁版本 + 启动失败明确报错 |
| 旧 workspace（v1.4 前）todo 字段缺 | buildStreamFromMessage 默认 `[]`（向前兼容） |
| .gitignore 解析失败 | 静默降级到默认 ignore 列表 |
| LLM 误用 `cd`（每条命令独立 shell） | systemPrompt 教学 + 工具描述明确 |
| webfetch 抓恶意大文件 | 100KB 硬上限 + 流式读取可中断 |
