# v1.7 — 资源库（取代 Marketplace）+ 三源统一设计

**版本**：v1.7.0
**作者**：Sisyphus（基于 brainstorming 会话产出）
**日期**：2026-08-11
**状态**：已实施（v1.7.0）

## 1. 背景

v1.6 把自定义上传的 MCP / Skill 单独放在 MarketplaceView 底部"自定义资源折叠区"——形成两套 UI：marketplace 装的资源在主网格，自定义上传的在折叠区，用户体验割裂。

v1.7 重新定位整个功能：**"商场"改为"资源库"**——统一管理 agent / mcp / skill 三类共享资源，三类 source：

1. **系统预置**（builtin）——应用打包自带，离线可用
2. **我的上传**（custom）——用户自定义上传
3. **网络资源**（marketplace）——远程 catalog 拉取的真 marketplace 包
4. **P2P 共享**（p2p）——v2 agent 互联时扩展（架构预留）

资源库作为未来分布式分发功能的入口——v2 P2P 互联时，"网络资源"自然延伸到"其他用户共享"。

## 2. 目标

- **取消底部"自定义资源"折叠区**——custom 资源直接出现在主网格
- **MarketplaceView → ResourceLibraryView**——重命名 + UI 重构
- **统一数据模型 `ResourceItem`**——取代现有 MarketplaceItem / InstalledSkill / RegisteredMcp 三结构
- **统一 IPC**——`resource:list` / `resource:getDetail` / `resource:install` / `resource:delete` 四通道
- **source 过滤 tab**——主网格顶部加 source 过滤维度
- **直接删除** v1.6 deprecated 文件 + IPC（不保留兼容）
- **架构预留** `source='p2p'` 字段——v2 加 `listP2PResources()` 即可

## 3. 非目标

- 不动 DB schema（agent_definitions 已有所需字段：source / created_at / default_tools 等）
- 不实现 P2P 资源拉取（v2）
- 不重写现有 add 弹窗（RegisterMcpDialog / UploadSkillDialog / DefinitionEditor 保留，仅 IPC 调用层改名）
- 不修改 builtin catalog 内容（catalog.json 不动）
- 不改 MarketplaceView 的 InstallCount / 校验状态等业务逻辑（迁移到 ResourceCard）

## 4. 关键决策汇总

| 维度 | 决策 | 理由 |
|---|---|---|
| 重命名 | MarketplaceView → ResourceLibraryView，标题"商场"→"资源库" | 用户定位升级——这是统一资源管理入口，不只是商场 |
| Source 分类 | builtin / marketplace / custom / p2p 四类 | 三类当前可用 + 一类 v2 预留 |
| 数据模型 | `ResourceItem` 取代 MarketplaceItem / InstalledSkill / RegisteredMcp | 统一前端展示，消除三结构并存 |
| 资源 ID | `${source}-${type}-${slug}` 命名约定 | 全局唯一 + 可路由（parseResourceId 反解三元组） |
| 上传入口 | 「+ 添加资源 ▼」下拉菜单（创建 Agent / 添加 MCP / 上传 Skill） | 单按钮整洁，三类 add 入口共享 |
| 双层 Tab | 类型 tab（全部/Agent/MCP/Skill）+ 来源 tab（全部/系统预置/我的上传/网络资源）AND 过滤 | 类型与来源是正交维度，两层 tab 直观 |
| 详情面板 | 按 source 分支显示不同字段 | builtin/marketplace/custom 字段差异大，分支显示信息更完整 |
| 删除/卸载 | 统一 `resource:delete(id)`，按 source 路由（builtin 抛错 / marketplace uninstall / custom 按 type 路由） | 单一接口，前端不感知差异 |
| catalog 现有 5 项归类 | 全部归 `builtin`（downloadUrl="" + author=Momo Studio） | 实际都是预置内联包 |
| 现有 deprecated 文件 / IPC | **直接删**（不保留 v1.8） | 用户明确要求，避免代码冗余 |

## 5. 架构总览

### 5.1 Source 分类

| Source | 含义 | 示例 | installed | installable | removable |
|---|---|---|---|---|---|
| `builtin` | 系统预置，应用打包自带 | catalog.json downloadUrl="" 项（pm-agent/coder/filesystem/code-review） | true | false | false |
| `marketplace` | 网络共享，远程 URL 下载 | catalog.json downloadUrl!="" 项（当前 0 个，未来扩展） | false（未装时） | true | true（已装时走 uninstall） |
| `custom` | 用户自定义上传 | RegisterMcpDialog 注册的 MCP + UploadSkillDialog 上传的 skill + DefinitionEditor 创建的 agent | true | false | true |
| `p2p` | (v2) 其他用户共享 | 未来 agent 互联时扩展 | v2 | v2 | v2 |

### 5.2 统一数据模型 ResourceItem

```typescript
interface ResourceItem {
  id: string;                  // `${source}-${type}-${slug}`
  type: 'agent' | 'mcp' | 'skill';
  source: 'builtin' | 'marketplace' | 'custom' | 'p2p';
  slug: string;
  name: string;
  description: string;
  version?: string;
  iconEmoji?: string;
  installed: boolean;
  installable: boolean;
  removable: boolean;

  // 来源特定字段（详情面板按 source 分支显示）
  builtin?: { category?: string; tags?: string[] };
  marketplace?: {
    author: string;
    readme: string;
    downloadUrl: string;
    checksum: string;
    verificationStatus: 'official' | 'verified' | 'community' | 'unverified';
    sizeBytes?: number;
    installCount?: number;
    tags: string[];
    category: string;
  };
  custom?: {
    installedAt: string;
    mcpConfig?: { command: string; args: string[]; env?: Record<string, string> };
    skillFrontmatter?: { name?: string; version?: string };
    agentSystemPromptHash?: string;
  };
  p2p?: { peerId: string; peerName: string };  // v2 预留
}
```

### 5.3 资源 ID 命名约定

```
${source}-${type}-${slug}

例：
  builtin-agent-pm-agent
  builtin-mcp-filesystem
  builtin-skill-code-review-workflow
  custom-mcp-github
  custom-skill-xlsx
  custom-agent-<uuid>     # agent def id 是 UUID（v1.3 重构后），不可读但唯一
  marketplace-skill-some-remote-skill
```

ID 后端可解析回 `(source, type, slug)` 三元组，路由到对应处理函数。

### 7.2 listResources(filter) 主入口

```typescript
import { listBuiltinResources } from './builtin';
import { listMarketplaceResources } from './marketplace';
import { listCustomResources } from './custom';

export async function listResources(filter?: ResourceFilter): Promise<ResourceItem[]> {
  // 三源并行拉取，部分失败不阻塞其他源（builtin/custom 总能成功，marketplace 可能 fetch failed）
  const [builtin, marketplace, custom] = await Promise.allSettled([
    filter?.source && filter.source !== 'builtin' ? Promise.resolve([]) : listBuiltinResources(),
    filter?.source && filter.source !== 'marketplace' ? Promise.resolve([]) : listMarketplaceResources(),
    filter?.source && filter.source !== 'custom' ? Promise.resolve([]) : listCustomResources(),
  ]);

  const items: ResourceItem[] = [];
  if (builtin.status === 'fulfilled') items.push(...builtin.value);
  if (marketplace.status === 'fulfilled') items.push(...marketplace.value);
  else logger.warn('listResources: marketplace 源失败，跳过', { reason: marketplace.reason });
  if (custom.status === 'fulfilled') items.push(...custom.value);

  return filter?.type ? items.filter((i) => i.type === filter.type) : items;
}

export async function resolveResourceById(id: string): Promise<ResourceItem | null> {
  const parsed = parseResourceId(id);
  if (!parsed) return null;
  const items = await listResources({ type: parsed.type, source: parsed.source });
  return items.find((i) => i.id === id) ?? null;
}
```

### 7.3 三源 list 函数实现

#### `listBuiltinResources()` — 系统预置

```typescript
// 数据来源：catalog.json 中 downloadUrl="" 的内联项（5 个）→ source='builtin'
// 复用现有 marketplace/client.ts 的 loadCatalogSync

export function listBuiltinResources(): ResourceItem[] {
  const catalog = loadCatalogSync();
  return catalog.items
    .filter((item) => !item.downloadUrl)
    .map((item) => fromCatalogItem(item, 'builtin'));
}
```

#### `listMarketplaceResources()` — 网络资源

```typescript
// 当前 catalog.json 全是 downloadUrl="" 内联项 → 真远程 marketplace 包 0 个
// 未来真接 marketplace 后，downloadUrl 非空项在这里返回

export async function listMarketplaceResources(): Promise<ResourceItem[]> {
  try {
    const catalog = await loadCatalogAsync();
    return catalog.items
      .filter((item) => item.downloadUrl)
      .map((item) => fromCatalogItem(item, 'marketplace'));
  } catch (err) {
    logger.warn('listMarketplaceResources: 远程 catalog 拉取失败', { error: (err as Error).message });
    return [];
  }
}
```

#### `listCustomResources()` — 用户上传

```typescript
// 合并三处：
//   1. mcp_definitions 表 source='custom'（v1.6 引入 source 列）
//   2. <userData>/skills/ 下有 .sha256 标记的目录
//   3. agent_definitions 表 source='custom'

export function listCustomResources(): ResourceItem[] {
  const result: ResourceItem[] = [];

  // MCP（复用 host-manager.listRegistered，过滤 source='custom'）
  for (const mcp of listRegistered().filter((m) => m.source === 'custom')) {
    result.push({
      id: `custom-mcp-${mcp.name}`,
      type: 'mcp', source: 'custom', slug: mcp.name,
      name: mcp.name,
      description: `自定义 MCP（${mcp.command}）`,
      version: mcp.version,
      installed: true, installable: false, removable: true,
      custom: {
        installedAt: mcp.installedAt,
        mcpConfig: { command: mcp.command, args: mcp.args, env: mcp.env },
      },
    });
  }

  // Skill（复用 zip-uploader.listInstalled，过滤 source='custom'）
  for (const skill of listInstalled().filter((s) => s.source === 'custom')) {
    result.push({
      id: `custom-skill-${skill.slug}`,
      type: 'skill', source: 'custom', slug: skill.slug,
      name: skill.name, description: skill.description,
      installed: true, installable: false, removable: true,
      custom: { installedAt: skill.installedAt ?? new Date().toISOString() },
    });
  }

  // Agent（复用 agent/crud.listAgentDefinitions，过滤 source='custom'）
  for (const def of listAgentDefinitions().filter((d) => d.source === 'custom')) {
    result.push({
      id: `custom-agent-${def.id}`,
      type: 'agent', source: 'custom', slug: def.id,  // agent def id 是 UUID
      name: def.name, description: def.description,
      iconEmoji: def.iconEmoji,
      installed: true, installable: false, removable: true,
      custom: {
        installedAt: def.createdAt,
        agentSystemPromptHash: hashPrompt(def.systemPrompt),
      },
    });
  }

  return result;
}
```

### 7.4 IPC Handler 注册

```typescript
// electron/src/main/resource/ipc.handlers.ts

export function registerResourceHandlers(): void {
  ipcMain.handle('resource:list', async (_evt, filter?: ResourceFilter) => {
    return listResources(filter);
  });

  ipcMain.handle('resource:getDetail', async (_evt, id: string) => {
    return resolveResourceById(id);
  });

  ipcMain.handle('resource:install', async (_evt, id: string) => {
    const item = await resolveResourceById(id);
    if (!item) throw new Error(`资源 ${id} 不存在`);
    if (!item.installable) throw new Error(`「${item.name}」不可安装`);
    if (item.source === 'marketplace') {
      return installPackage(item);  // 复用现有 marketplace/installer.ts
    }
    throw new Error(`source=${item.source} 不支持 install 操作`);
  });

  ipcMain.handle('resource:delete', async (_evt, id: string) => {
    const item = await resolveResourceById(id);
    if (!item) throw new Error(`资源 ${id} 不存在`);
    if (!item.removable) {
      throw new Error(`「${item.name}」是${sourceLabel(item.source)}，不可移除`);
    }
    switch (item.source) {
      case 'marketplace':
        return uninstallPackage(item.slug);
      case 'custom':
        if (item.type === 'mcp')   return deleteRegistered(item.slug);
        if (item.type === 'skill') return deleteCustomSkill(item.slug);
        if (item.type === 'agent') return deleteDefinition(item.id);
    }
  });

  logger.info('Resource IPC handlers 已注册');
}
```

### 7.5 IPC 通道

#### 新增（v1.7）

| 通道 | 入参 | 返回 | 用途 |
|---|---|---|---|
| `resource:list` | `{ type?, source? }` | `ResourceItem[]` | 统一列表 |
| `resource:getDetail` | `id` | `ResourceItem \| null` | 详情面板按需拉取 |
| `resource:install` | `id` | `void` | marketplace 资源安装（封装现有 install） |
| `resource:delete` | `id` | `void` | 统一删除/卸载（按 id 路由） |

#### 保留（不动）

- `mcp:register` / `mcp:start` / `mcp:stop` / `mcp:listTools` / `mcp:callTool` — MCP 进程管理仍需要
- `agent:createCustom` / `agent:updateDefinition` / `agent:getAssignmentDeltas` / `agent:setAssignmentDeltas` — Agent 编辑 + Layer 3 仍需要
- `skill:uploadZip` — 上传入口仍需要

#### 直接删除（不保留 deprecated）

- `mcp:listRegistered` / `mcp:deleteRegistered` → 合并到 `resource:list` / `resource:delete`
- `skill:listInstalled` / `skill:deleteCustom` → 合并到 `resource:list` / `resource:delete`
- `marketplace:loadCatalog` / `marketplace:install` / `marketplace:uninstall` → 合并到 `resource:list` / `resource:install` / `resource:delete`

**注意**：底层函数（`listRegistered` / `listInstalled` / `loadCatalog` / `installPackage` / `uninstallPackage` 等）**保留**作为 `resource/` 内部复用，仅删除 IPC handler + preload 暴露。

### 7.6 CapabilityTabs 改用 resource:list

DefinitionEditor / CapabilityTabs（v1.6 调 `ipc.mcp.listRegistered` / `ipc.skill.listInstalled` 拉动态列表）→ v1.7 改用 `ipc.resource.list({type:'mcp'})` / `ipc.resource.list({type:'skill'})`，过滤掉 `source='builtin'` 与 `source='marketplace'` 的不可选资源（或保留全部，让用户选）。
