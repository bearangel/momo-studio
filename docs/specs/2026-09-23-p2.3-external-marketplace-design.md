# P2.3 移除网络获取 + 外部市场快捷打开 — 设计

- 日期：2026-09-23
- 状态：已批准（用户 2026-09-23 逐题裁定：去除深度 A / 预置入口 A / 形态 B / 外链清单四项全确认）
- 上游：P2 双轨 Hub（`2026-09-22`）/ P2.1 Smithery 直连（`2026-09-23-p2.1`）/ P2.2 配置编辑（`2026-09-23-p2.2`）
- 版本：合入后 `2.1.0-alpha.5`
- 后继：momo-hub 统一市场（自有服务，未来单独立项）

## 1. 背景

外部市场（GitHub Raw marketplace catalog + Smithery registry）适配成本高、
质量不可控（Smithery 平台 token 墙 / catalog 维护负担）。战略调整：**应用内不再
承诺「网络下载安装」**，资源获取收敛为「本地导入 + P2P 分享」；外部市场改为
**快捷打开**（系统浏览器跳转，Cherry Studio 式），为将来 momo-hub 自有统一市场
让路。

## 2. 目标与非目标

**目标**：
1. renderer 移除「网络获取」模式（Segmented / RegistryBrowse / registry 安装流 /
   McpConnectDialog 接线）
2. 每类型页工具栏提供「外部市场」按钮 + 弹出面板，按类型列外部市场快捷打开
3. 预置 agent 启用入口迁至 AddMenu「启用预置库」（零网络）
4. electron 现有 hub/marketplace 管线与 IPC 契约**原样保留**（momo-hub 复用地基）

**非目标**：momo-hub 本体；electron 侧任何管线删改（除两个小新增通道）；P2P 分享
（保留不动）；stdio MCP 编辑；Smithery OAuth。

## 3. 移除面（仅 renderer）

| 对象 | 动作 |
|---|---|
| `TypePageShell.tsx` | 删 Segmented 双态切换（恒「已安装」单态）、删 `RegistryBrowse` 挂载、删 registry `onInstall` 包装流；工具栏原 Segmented 位置换「外部市场」按钮 |
| `RegistryBrowse.tsx` + 测试 | 删除文件 |
| `McpConnectDialog.tsx` + 测试 | 删除文件（Smithery needsConfig 弹窗，触发点随安装流消亡） |
| `ResourceLibraryView.tsx` | 删 registry install / McpConnectDialog / EnablePreset（registry 侧）接线；保留 DXT/MCPB 导入、mcp-json 粘贴、skill 上传、agent 新建/导入弹窗接线 |
| `resource.store.ts` | 删 `mode` / `setMode` / `registryProviderKey` / `setRegistryProvider` 及相关持久化 |
| `ResourceDetail` 等 | registry 分支死代码清理（`installNotice` 保留——本地上传导入也用它） |

**保留不动**：`renderer/src/ipc/types.d.ts` 与 preload 的全部 registry IPC 契约
（`registryProviders` / `registryList` / `install` / `installSmitheryRemote` 等——
electron 侧实现与测试全部原样，UI 仅仅不再调用）；`Segmented` 组件本身（若他处
仍有消费者；无消费者则一并删，Task 0 核验）。

## 4. 外部市场按钮 + 弹出面板（新组件 `ExternalMarketplacePopover`）

- 位置：三类型页工具栏右侧（原 Segmented 位），lucide `ExternalLink` 16px
  stroke 1.75，按钮文案「外部市场」
- 面板：点击展开（Popover 定位，Esc/遮罩关闭），标题按类型（「MCP 市场」/
  「Skill 市场」/「Agent 市场」），列市场卡片：名称 + 一句中文描述 + 「打开 ↗」
- 清单（配置常量，按 type）：
  - **MCP**：Smithery（最大 MCP registry）/ mcp.so（中文友好目录）/ Glama /
    PulseMCP（MCP 搜索引擎）/ MCP 官方目录（github.com/modelcontextprotocol/servers）
  - **Skill**：skills.sh（Claude skills 市场）/ ClawHub（clawhub.ai）
  - **Agent**：momo-hub 预告卡（不可点，标注「官方统一市场 · 即将上线」）
- 面板底部两行常驻小字（替代 toast，零新基建）：
  1. 「在浏览器打开 · 应用内不安装」
  2. 「回来怎么装：MCP 用＋菜单「粘贴 MCP JSON / 导入 .dxt .mcpb」；Skill 用＋菜单上传 zip；Agent 用＋菜单新建或导入」
- 打开动作：`shell.openExternal`（Task 0 核验 renderer 现有开外链通道；无则新增
  4 行小 IPC `misc:openExternal(url)`——url 强制 https，调用面仅为 Popover 内
  清单常量，无需域名白名单）

## 5. 预置库（新组件 `PresetLibraryDialog`）

- AddMenu 加「启用预置库」项——仅该类型有本地预置时显示（预期仅 agent 页；
  mcp/skill 预置有无由 Task 0 核验 `resources/` 与 builtin 清单，无则不渲染）
- 数据：新轻量只读 IPC `resource:listBuiltinPresets(type)`——从
  `resources/agents/*.yaml` 本地直读（`builtin.ts` 现有解析函数复用），零网络，
  不触碰保留的 fetchCatalog 管线
- 流程：列表（名称/描述/emoji）→ 选中 agent → 现有 `EnablePresetDialog` 配模型
  → 启用（`enablePresetWithJoin` 现有链路不动）

## 6. electron 新增（全部小面，不动保留管线）

1. `resource:listBuiltinPresets` handler（只读本地，约 20 行）
2. `misc:openExternal`（若无现成通道；url 校验 https 后 `shell.openExternal`）

## 7. 错误处理

| 场景 | 行为 |
|---|---|
| openExternal 失败/被系统拦 | 中文 toast/面板红字，面板不关闭 |
| listBuiltinPresets 读失败 | 弹窗内红字 + 重试（空态文案「预置清单读取失败」） |
| 无预置类型点入口 | 入口本身不渲染（非空态弹窗） |
| momo-hub 预告卡点击 | 无动作（非禁用态欺骗，直接不可点样式） |

## 9. 决策记录

- D1 去除深度 = UI 层移除、electron 管线全保留（momo-hub 复用地基 + 现成测试资产）
- D2 预置入口 = AddMenu「启用预置库」弹窗（零网络本地清单，复用 EnablePresetDialog）
- D3 外部市场形态 = 工具栏直达按钮 + Popover 卡片（原 Segmented 位，替代感最强）
- D4 外链清单 = MCP×5 / Skill×2 / Agent 仅 momo-hub 预告（不放凑数链接）
- D5 「回来怎么装」= 面板内常驻两行小字（不引入 toast 基建）
- D6 registry IPC 契约两端保留（renderer 只是停用调用）——momo-hub 时代直接复用
- D7 McpConnectDialog 删除（触发点消亡；momo-hub 按新契约重写，schema 契约在
  electron 侧完整保留）
