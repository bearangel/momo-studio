# P2.6 Skill 从 Git 仓库导入 设计

- 日期：2026-09-24
- 状态：已批准（用户逐节确认）
- 范围：skill 页新增「从 Git 仓库导入」——输入 GitHub/GitLab 仓库地址，自动发现全部 SKILL.md 并批量导入
- 上游：v1.6.2 zip 批量上传（AdmZip/.sha256 幂等语义）、P2.5 D3 横幅化模式

## 1. 背景

用户诉求：输入 `https://github.com/obra/superpowers` 这类仓库地址，把仓库内全部技能导入 Momo Studio。superpowers 结构 `skills/<名>/SKILL.md` + `references/` 资产——与现有 skill 目录布局完全对口。

**机制约束（用户裁定）**：不用 `git clone`——终端用户可能未装 git。改用各平台官方 **HTTPS zip 归档**下载（GitHub codeload / GitLab archive），复用既有 AdmZip，**零 git 依赖、零新依赖**。

## 2. 决策记录

| # | 决策 |
|---|---|
| D1 | 取包：HTTPS zip 归档（`HEAD` 自动解析默认分支）——github → `codeload.github.com/<owner>/<repo>/zip/HEAD`；gitlab → `gitlab.com/<owner>/<repo>/-/archive/HEAD/<repo>.zip`。host 白名单适配器结构，gitee 等后续可加 |
| D2 | 结构适配：剥顶层归档目录（`<repo>-<branch>/`）后**全深度**扫 `**/SKILL.md`；每个 SKILL.md 的**父目录** = 一个 skill（slug=父目录名；根级 SKILL.md 用 frontmatter.name 转 kebab）——比 zip 上传的 ≤2 段限制更宽，适配任意仓库布局 |
| D3 | 两阶段交互（用户选定）：扫描（下载+解析）→ 预览（列表+同名覆盖警示）→ 确认导入 → 全成功自动关+绿横幅「导入成功 N 条技能」（复用 P2.5 D3 模式）/ 有失败留窗明细 |
| D4 | 幂等/覆盖：**逐 skill 目录内容 hash**（相对路径+文件内容串接）写 `.sha256`——同 hash 跳过、不同 hash 覆盖（=更新；重导入即全量更新语义）。比 zip 的整包共享 hash 更准（跨仓库重导入同内容才跳过） |
| D5 | 两通道避免二次下载：scan 把 zip 落临时文件（`<userData>/tmp/git-import-<id>.zip`），importId 模块级 Map 持路径；import 一次性消费后清理；扫描前扫残留 `git-import-*` 前缀清一次（进程崩溃残留兜底；import 前清会自毁当前会话 tmp——时序勘误定为 scan 前） |
| D6 | 边界：仅公开仓库（404/401 → 「仓库不存在或为私有，当前仅支持公开仓库」）；下载 60s 超时 + 100MB 流式上限；URL 兼容尾斜杠/`.git` 后缀 |

## 3. electron 服务（`skill/git-import.ts` 新文件）

```ts
/** 扫描结果条目（types.d.ts 镜像源） */
export interface ScannedSkill { slug: string; name: string; description: string }

/** 解析仓库 URL → 归档 zip URL；不支持 host / 非 https 抛中文错（列支持清单） */
export function buildArchiveUrl(repoUrl: string): string;

/** 下载 zip（超时/大小上限）→ AdmZip 解析 → 剥顶层目录 → 全深度扫 SKILL.md → tmp 落盘 */
export async function scanGitRepoSkills(
  repoUrl: string,
  deps?: { fetchZip?: (url: string) => Promise<Buffer>; tmpDir?: string },  // 测试注入
): Promise<{ importId: string; skills: ScannedSkill[] }>;

/** 读 tmp → 逐 skill 提取父目录全部文件 → 落 <skillsDir>/<slug>/（三层路径防御 + isIgnoredEntry 同款 + 跳 .git/）→ 逐 skill 内容 hash 写 .sha256 → 清理 tmp */
export async function importGitRepoSkills(
  importId: string,
  deps?: { skillsDir?: string },
): Promise<{ imported: UploadedSkill[]; failures: Array<{ slug: string; reason: string }> }>;
```

要点：
- 下载用 Electron net/fetch 流式收集并计数，超限即断（中文报错含上限值）
- **顶层剥除判定**：全部条目共享同一顶层目录段（GitHub/GitLab 归档恒如此）才剥；多个顶层段或无包裹则原样处理（防异常归档误剥）
- frontmatter 解析复用 zip-uploader 的 `parseFrontmatter`（宽容不抛错，name/description 供预览）
- slug 合法性校验（空/`..`/路径分隔符拒）与 zip 上传同口径；根级 SKILL.md 的 slug 兜底链：`nameToSlug(frontmatter.name)` → 仓库名（URL 解析所得，`.git` 后缀已剥）
- importId 用 `randomUUID()`；Map 中取出即删（一次性）；不存在 → 「导入会话已失效，请重新扫描」

## 4. IPC 双端（types.d.ts / preload / ApiSurface 三处镜像）

```ts
// resource 命名空间追加（GitImportResult = { imported: UploadedSkill[]; failures: Array<{ slug; reason }> }，
```

通道名 `resource:scanGitRepoSkills` / `resource:importGitRepoSkills`；导入成功后 fire-and-forget `broadcastLocalResourceCatalog()`（与 registerMcp/uploadSkillZip 同款）。

## 5. renderer（`GitImportDialog.tsx` + AddMenu 项）

- skill 页 addItemsFor 加 `{ key: 'git-import', title: '从 Git 仓库导入…', hint: 'GitHub / GitLab 地址，自动发现全部 SKILL.md' }`
- 阶段机（照 McpJsonPasteDialog 模式）：`input`（URL 输入 + https/github/gitlab 前端校验 disabled + 「扫描」）→ `review`（skills 列表：名称+描述+slug code；`ipc.resource.list({type:'skill'})` 查同名 → 警示「将覆盖 N 个同名技能：…」；「返回修改 / 确认导入 N 条」；skills 空 → 「未发现 SKILL.md（要求仓库内含 SKILL.md 文件）」）→ `importing`（「导入中…」）→ `done`（全成功：`installNotice` 横幅 + 自动关——P2.5 D3 同款；有失败：留窗逐条明细 + 关闭按钮）
- View 层 `gitImportOpen` state 挂载，onSuccess 刷新列表

## 6. 安全与边界汇总

| 面 | 防线 |
|---|---|
| URL | https 强制 + host 白名单（github.com / www.github.com / gitlab.com），其余报错列支持清单 |
| 下载 | 60s 超时；100MB 流式上限 |
| 解压/落盘 | 三层路径防御（`..` / resolve 越界 / 符号链接）+ isIgnoredEntry 同款 + 防御性跳 `.git/`；slug 合法性校验 |
| 临时文件 | `<userData>/tmp/`；一次性消费；扫描前清残留（勘误：非导入前——会自毁当前会话） |
| 私有仓库 | 明确中文报错（当前仅公开） |
