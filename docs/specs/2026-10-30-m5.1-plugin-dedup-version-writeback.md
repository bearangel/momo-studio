# M5.1 热修：插件×本地副本去重 + 发布版本回写（library-plugin-dedup）

- **日期**：2026-10-30
- **状态**：待评审（Momus）
- **范围**：studio 单侧；协议零改、hub 零改
- **来源**：用户真机验收暴露三根因（数据实证见 `.omo/feature-matrices/2026-10-30-m5.1-hotfix.md` §0）：
  - RC1：superpowers 插件提供 15 技能 × `~/.momo-studio/skills/` 存 11 个同名 zip 导入副本——聚合层（custom.ts 2a 与 2 两段循环）零去重 → 技能面板 11 组双卡；mcp/agent 同模式
  - RC2：发布 v1.0.1 到 hub 成功（owner 已认领）但本地定义不回写版本（brainstorming SKILL.md frontmatter 无 version 字段，恒显 1.0.0）——「本地是本体」哲学缺口
  - RC3：旧码装的 hub 副本清理入口藏在设置页 hub 面板，发现性差
- **用户裁定（2026-10-30）**：去重策略 = **插件优先 + 本地副本隐藏 + 面板一键清理**

## 1. 设计

### 1.1 插件优先去重（RC1）

- **展示层**：`listResources` 出口（installed 收窄点同层）对同 `type+slug` 做**插件优先归并**——插件行在场时，custom 本地副本行不输出（隐藏非删除；id 体系不变）
- 覆盖三类型：skill（fs 副本）/ mcp（custom mcp_definitions 同名）/ agent（custom def 同 slug）
- **不动**：builtin × custom 不归并（用户可能刻意 fork 预置，语义不同）；marketplace × custom 不归并（罕见，无实据）
- **重复检测 + 一键清理**：库页检测「插件已提供同名的本地副本」→ 页顶提示条「检测到 N 个与插件重复的本地副本 · 一键清理」→ 批量删除（skill=删 fs 目录+sha256 标记；mcp/agent=删 DB custom 行）；删除失败逐条报错不中断
- 清理入口前置：提示条常驻库页（有重复才渲染）；设置页 hub 并存小票保留（职责不同：那个管 hub×custom）

### 1.2 发布版本回写（RC2）

- 发布成功（201 回执）→ **版本写回本地定义**：
  - skill：SKILL.md frontmatter 写/更新 `version: <发布版本>`（保留其余字段与正文；原子写）
  - agent：`agent_definitions.version` 更新（DB）
  - mcp（custom）：`mcp_definitions.version` 更新（DB）
  - plugin：本地注册开发目录的插件可写 manifest 版本；非本地管理的插件（随包分发不可变）跳过并在发布回执提示「插件本体由插件包管理，版本未回写」
- 回写后本地卡版本即时与 hub 发布态一致（徽标「已发布 vN」的 N 与本地版本同源化）
- 回写失败不推翻发布（hub 已落库）——toast 警示「发布成功但版本回写失败：{原因}」

### 1.3 导入/安装双向拦截（RC1 预防）

- **导入拦截**：skill zip 导入（zip-uploader）遇插件已提供同名 slug → 拒绝 + 人话「插件 {pluginId} 已提供技能 {slug}，无需导入副本」
- **安装拦截**：`assertNoLocalSlugConflict` 的 `hasLocalSlugEntity` 扩纳入 **plugin 源**（hub 安装遇插件同名 → 同 M5.0 拦截口径人话「插件已提供同名技能…」）
- 双向堵新增路径，配合一键清理消化存量

### 1.4 徽标版本源（RC2 收尾）

- 「已发布 vN」徽标的 N 取 hub 目录 latest（现状核对——若现状取本地版本则修正为 hub latest）

## 2. 测试计划

- **electron**：归并矩阵（plugin×custom 三类型 / builtin×custom 不归并负例 / 隐藏不删除——直查源仍在）；清理批删（成功/部分失败续删）；回写三通道（skill frontmatter 原子写/agent DB/mcp DB）+ plugin 不可写跳过提示 + 回写失败不推翻发布；导入拦截正反；安装拦截扩 plugin 源
- **renderer**：提示条渲染（N 计数/无重复不渲染/一键清理调 IPC 后刷新）；卡版本随回写更新
- **e2e**：沿 mock hub——发布新版→本地版本=hub 版本；导入插件同名 zip→拒绝；面板提示条→清理→双卡消失插件卡保留
- **回归锁**：M4.5 收窄/M5.0 五处变化全部既有锁零回归

## 4. 非目标

- 自动删除（一律用户一键确认）
