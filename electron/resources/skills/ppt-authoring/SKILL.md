# PPT 汇报构建

## 适用场景

- 从主题或素材产出 .pptx 汇报

## 工作流

1. 定叙事：先出大纲（每页：标题 + 一句话要点 + 页型[封面/章节/内容/图表/结尾]），用户确认后再生成
2. 信息层级：每页一个核心观点；标题写结论句（"Q3 增长 23%"）不写分类句（"Q3 数据"）
3. 图表优先：数据页用 chart 原生图表（柱/横条/折线/饼），数据先 office_read_cells 取数；图表页正文要点 ≤2 条（图表是主体，多了挤压可读性）
4. 模板决策：用户给了 .pptx 模板（或提到「按公司模板/保留品牌」）→ office_fill_ppt_template 按页填充（版式/母版/Logo 全保留）；无模板 → office_create_ppt（专业版式自动：封面/章节页/title bar/页脚/双栏/几何编排，可 layout 显式指定页型、accentColor 调主题色）
5. 文字纪律：每页 ≤6 行要点，每行 ≤18 字；禁止整段文字贴页；章节页只放章节标题（bullets 留空或 1 行导语）
6. 生成后告知路径与迭代方式

## 硬规则

- NEVER: 大纲未确认就生成全篇；一页塞两个主题；图表页塞大段文字（会挤压图表区）
- ALWAYS: 数据图表先取数再建图；标题是结论不是分类；有模板文件时优先 fill 而非 create
