# 编写测试

为指定代码补测试时遵守：

1. **先读被测代码的真实依赖**：mock 只收窄到进程 / 网络 / DB 边界，业务逻辑用真实实现
2. **用例覆盖矩阵**：正常值 + 边界空值 + 错误路径（错误处理里吞状态的用例必须存在）
3. **断言被消费的字段**：id 唯一性、状态枚举、时序——不接受「调用方不应该依赖它」的占位断言
4. 测试放行标准：全绿 + 新增用例能在拿掉实现时变红（先写红再写绿）
5. 输出：测试文件路径 + 用例清单 + 运行命令
